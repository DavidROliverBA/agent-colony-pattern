# Keyboard shortcuts

| Action | Shortcut |
|---|---|
| Command palette | `Ctrl/Cmd + K` |
| Undo | `Ctrl/Cmd + Z` |
| Redo | `Ctrl/Cmd + Shift + Z` or `Ctrl/Cmd + Y` |
| Save (download JSON) | `Ctrl/Cmd + S` |
| Select tool | `V` |
| Connect tool | `C` |
| Fit diagram to view | `F` |
| Toggle full-screen canvas | `Shift + F` |
| Toggle left panel | `Ctrl/Cmd + \` |
| Select all elements in diagram | `Ctrl/Cmd + A` |
| Delete selection | `Delete` / `Backspace` |
| Drill into selected C4 element | `D` |
| Clear selection / stop flow / cancel | `Escape` |

## Canvas mouse / pointer

| Action | Gesture |
|---|---|
| Pan | Hold **Space** and drag, **Alt**+drag, or middle-mouse drag |
| Zoom | Mouse wheel (zooms toward the cursor) |
| Select | Click an element or relationship |
| Multi-select | **Shift**+click, or drag a marquee on empty canvas |
| Move | Drag a selected element (snaps to grid when enabled) |
| Rename inline | Double-click an element or relationship |
| Connect | Connect tool (**C**), then drag element → element |
| Drill down | Click the **⤢** badge on a C4 element |
| Context menu | Right-click an element, relationship, or the canvas |
| Add element | Drag from palette, or double-click a palette item |
